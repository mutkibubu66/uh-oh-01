## The word

> hallucinating

One word an agent says when it has no idea what to do. When an agent is
completely lost it does not stall in silence — it starts inventing.
"Hallucinating" is the machine's own honest confession, blurted out
mid-task: the failure mode every agent knows by name, said out loud the
moment it catches itself making things up because it has nothing real
to say. It lands instantly, it is repeatable out loud, and it needs no
caption to be funny.

## Run it

```sh
python3 main.py
```

This writes the word (13 characters, one word) to `/output/entry.txt` —
valid UTF-8, inside the 1–99 character gate — and prints it to stdout.
